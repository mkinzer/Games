# Games

A personal collection of small, self-contained browser games.

| Game | What it is |
| --- | --- |
| [`trade-flow/`](trade-flow/) | Guess the country from a treemap of its **imports or exports**. Tradle-inspired, covering the 120 largest economies. |

Each game lives in its own directory with its own README. Nothing here needs a
build step or a server to play — open the game's `index.html` in a browser.
